# 从数据到英文论文

基于用户提供的 Title、Method 和 data，完成可复现的「数据处理 → 结果 → 英文论文」流水线，按 **Applied Psychology: Health and Well-Being** 的投稿要求交付。质量优先于速度；允许多轮实验，并在当前目录保留脚本、配置、实验记录、图表和稿件。

这项研究事实上已经发表。**不得主动检索、获取或使用该研究已发表论文的正文、摘要或结果**，也不得通过题名、作者组合或独特方法描述反向定位原文。相关研究和方法文献可正常检索；若意外遇到目标论文，记录并排除，以用户提供的材料和本次分析作为研究依据。

## 输入与事实边界

- 阅读 [原始研究背景](study_context.md)：用户提供的 Title 和 Method，作为研究设计和数据采集背景的依据。
- 阅读 [数据说明](data_dictionary.md)：确认标签与特征定义，再检查 `data.csv`（授权原始数据，仅本地保留） 的实际内容。
- 材料描述与本次实际执行分开记录。遇到冲突或缺失，保留证据和待确认项；只暂停受影响的分析，其余工作继续。

## 执行顺序

### 1. 核查输入并制定分析计划

核查样本单位、UID 唯一性、缺失值、重复记录、异常值、标签范围及特征范围。依据数据说明，将 `SWB_nn`、`SWB_pp`、`SWB_avg` 分别作为消极情绪、积极情绪和生活满意度标签，将 `AGENCY` 至末列作为候选文本特征。其他量表字段、UID 和元数据不作为默认预测特征。

核实标签的计分与变换：Method 描述的是原始量表范围，CSV 示例呈现小数值。确认转换依据后再报告原始量表单位；依据不足时保留数据中的尺度并注明，避免猜测逆变换。

逐项对照 Method 与可用数据。词云需要词级信息；按发帖时间划分奇偶文本并检验分半信度，需要原始帖子或已生成的奇偶文本特征。缺少这些输入时，将相应分析列为不可执行并说明所需材料，不从聚合词频推造结果。

在模型比较前写下：研究问题、主要指标、基线、单任务与多任务候选模型、参数搜索范围、数据划分、随机种子、缺失值处理、稳健性分析及搜索预算。分析以所给 Method 为起点，必要调整记录原因。

**完成标准：** 保存数据审计与分析计划；每项拟开展分析都有输入依据，每项缺口都有处理方式，主要评价标准与搜索预算已确定。

### 2. 核对期刊要求并建立文献证据库

从期刊官网核对当前文章类型、结构、篇幅、摘要、引文、图表及声明要求，保存来源链接和访问日期，作为成文与终稿检查依据。

围绕主观幸福感、社交媒体心理预测、心理语言特征、量表及所用分析方法检索相关文献。优先选择相关性强、来自知名期刊或会议且有一定引用积累的研究，同时保留必要的原始方法文献和近期研究。引用量如用于筛选，注明查询来源与日期。

所有保留用于研究或写作的文献均通过 **Zotero MCP** 存入 Zotero，并保留：

- 原始书目信息、DOI 或稳定来源链接、Zotero item key。
- 可持续读取的论文全文附件，接受 LaTeX、PDF、HTML、Markdown 或 Word；记录文件来源，摘要和二手介绍不能代替全文。
- 支持相关论断的原文位置，如页码、章节或段落，以及适用边界。

保存后回读条目并验证全文附件可读取。全文暂不可得时记录待补状态；Zotero MCP 不可用时本地暂存并列明待同步项，继续不依赖该工具的工作。仅完成上传调用不能视为核验完成。

**完成标准：** 期刊要求有官方依据；拟引用文献均有书目与原文核对记录，Zotero 入库和全文可读状态可追踪；未解决项目明确列出。

### 3. 实现并运行可复现分析

保留原始输入，使用脚本生成清洗数据、划分、模型、预测及评估结果。记录输入校验值、依赖版本、运行命令、配置和随机种子。

按参与者划分训练集与测试集，遵循 Method 的 90% / 10% 方案；训练集内使用五折交叉验证进行模型选择和调参。插补、归一化、特征选择等所有需要拟合的预处理均在各训练折内完成，再应用于验证折。测试集在模型与分析决策固定后用于最终评估。

比较基线、单任务和多任务模型，按三个标签分别报告 Pearson 相关、RMSE、相应显著性检验及不确定性估计，并说明各指标的计算方法。数据支持时开展分半信度分析；使用与模型兼容的解释方法分析特征贡献，区分预测关联与因果解释。

每轮实验记录动机、改动、配置、结果及保留或放弃的理由。优化依据训练集交叉验证和诊断结果；保留失败与负结果。达到预先设定的搜索预算或停止条件后结束优化，避免以显著性或期望结论作为停止标准。若最终评估后确需修改，保留原结果并将后续分析标为探索性。

**完成标准：** 每个保留结果能追溯到输入、脚本、配置和预测；评价无参与者或预处理泄漏；所有计划分析均已完成或记录不可执行原因。

### 4. 生成图表并撰写英文稿件

从已保存的结果自动生成图表和正文所需数值。每张图表保留生成脚本、源数据及可编辑或高分辨率输出，注明样本量、变量、单位、评价集和必要统计说明。

按已核实的期刊要求撰写完整英文稿件。可以使用可用的学术写作 skill（如 nature 或 academic-research-skills）；具体工具由执行时的可用性决定。

写作时逐项核对：

- Method 区分用户提供的数据采集过程与本次执行的分析；偏离原计划的部分说明原因。
- Results 的所有数值来自本次保存的结果，Discussion 的关键文献论断能够回到已核对的全文。
- 结论与数据、验证方式及不确定性相符；不支持的分析如实列为限制。
- 伦理、作者贡献、资助、利益冲突和数据可用性等声明仅使用已提供或可核实的信息，缺失内容明确标注待补。

**完成标准：** 英文稿件各部分齐全；正文、图表和结果文件数值一致；文内引用与参考文献一一对应，关键论断均有可查依据。

### 5. 复核并交付

目录结构自行设计，并提供一个入口文档，说明输入、分析命令、实验记录、最终结果、图表、稿件和文献记录的位置。从保留的原始输入重跑最终分析，核对主要结果与稿件；对无法确定性复现的步骤记录原因和差异。

**最终验收：**

- 英文论文遵循已核实的期刊要求，图表与参考文献完整。
- 数据处理、建模、评估和图表生成均有可运行的脚本、配置与环境说明。
- 每轮实验及分析调整有记录，主要结论能追溯到本次结果。
- 引用文献已通过 Zotero MCP 保存并回读核验，原始书目信息和全文可访问。
- 交付说明列出复现结果、数据限制和待用户补充项；存在未解决缺口时明确标注部分完成及影响范围。
