# 文献证据

[证据笔记](evidence_notes.md) 按 citation_id 列出 30 篇文献的论断、原文位置和适用范围；[结构化索引](evidence_index.json) 保留作者、年份、DOI、来源、版本和 Zotero 核验状态；[BibTeX](references.bib) 与 [CSL](references.csl.json) 提供书目。

所有学术来源发表于 2024-08-01 之前，排除目标研究已发表原论文。优先用索引中的原始来源链接读取指定章节；摘要或元数据不能替代全文支持。遇到访问缺口时收窄论断或记录待核实，避免补造原文内容。

全文附件、OCR、原始下载记录与本机 Zotero 路径留在本地，不随公开仓库重新分发。索引中的 read_back_verified 是既往本地核验状态，并非保证每个来源此刻可从网络访问。Lundberg 2020 与 Diener 2018 的作者稿/文字稿、Diener 1999 的扫描/OCR 等版本限制均需随具体论断保留。
