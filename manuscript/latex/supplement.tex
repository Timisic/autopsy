\section{Analysis provenance and missing inputs}\label{analysis-provenance-and-missing-inputs}

This supplement accompanies the participant-level Weibo reanalysis. The original supplied study is known to have been published, but its article, abstract and results were not retrieved or used. Data collection details are attributed to the supplied Method. Original inputs and hashes, row-level inclusion decisions, all parameter candidates, warnings and failed runs, fitted models, predictions, resampling code, figures, and source documents are retained in the package.

The questionnaire transformation cannot be identified from decimal values alone. Original PANAS/SWLS unit conversions, item reliability, odd/even-text reliability, word clouds, demographic validity and temporal cutoff reconstruction were not performed. Metadata indicate text extending beyond questionnaire completion for 1,027 primary participants, so these results cannot establish prospective prediction. An ind value above one occurred for 34 participants, and 13 feature codes lack mappings. No post hoc distribution-based cleaning was applied.

\section{Exact model selections and search records}\label{exact-model-selections-and-search-records}

The development-only grid had 42 configurations and 210 composite fold fits. Independent outcomes selected separate parameters; shared models selected one setting. All fitted transforms used only each fold\textquotesingle s training rows. Candidate checkpoints preserve scores, warnings, status, and OOF arrays with a separate explicit UID row-order file. The initial vector-scaling preflight and corrected scalar-scaling final implementation are both retained. The correction was triggered by a synthetic numeric consistency check before holdout evaluation, with no change in grid or participant split.

\section{Attribution and permutation diagnostics}\label{attribution-and-permutation-diagnostics}

TreeSHAP used Shared RF fitted on 933 participants. The largest error in reconstructing training predictions from expected value plus feature attributions was 2.22e-16 CSV units. The union of the ten highest-ranked training features for each target contained 14 distinct features. These features were permuted one at a time on the 104 holdout participants with 20 shuffles each. Mean delta RMSE and shuffle SD measure conditional model sensitivity. Their uncertainty is not a population confidence interval, and correlated categories may substitute for each other. Full signed contributions, expected values, input values and participant keys are retained in results/primary/interpretation/training\_\allowbreak{}shap\_\allowbreak{}values.npz.

\section{Independent computational reproduction}\label{independent-computational-reproduction}

The final analysis was rerun from data.csv in a separate output directory using the locked environment. Participant manifests, CV row order, selected parameters, CV fold scores, primary predictions and reported primary metrics agreed within 1e-12. Maximum absolute primary prediction difference was 0.0e+00. This is computational reproducibility on the same input and environment, not an independent sample replication. The JSON verification report lists exact checks and any intentionally omitted nonprimary scenarios. Repeated development CV was retained from the original final run and was not necessary to repeat for the primary prediction equivalence check.

\section{Exploratory optimization after the primary analysis}\label{exploratory-optimization-after-the-primary-analysis}

The 22-configuration search was fixed after the original holdout had been inspected. It used the same 933 development participants and 104 holdout participants. Five outer development folds each performed five-fold inner selection, followed by a five-fold search on all development data: 132 candidate-by-search records and 660 composite fold evaluations. All completed without failures or captured warnings. Scalar-target estimators were fitted independently unless the candidate explicitly shared outputs. Ridge, support-vector regression, elastic net and the shallow boosting alternatives tested different smoothness/regularization assumptions; PLS tested low-dimensional covariation. Every fitted imputer, scaler and target transformation used only the relevant training fold. Fixed log1p transformation was applied only to nonnegative input features. This was an exploratory extension, not a newly independent confirmation set.

Outer folds selected the original shared forest once, elastic net with alpha 0.1 and L1 ratio 0.5 twice, and independent forests with leaf size 60 twice. Variation in these choices is retained as a diagnostic. Table S3 gives unweighted means and descriptive SDs across the five outer folds; these SDs are not standard errors or confidence intervals, and overlapping training sets are not treated as independent replicates.
