# 微博主观幸福感研究术语

## Language

**主观幸福感**：参与者对自身情绪体验与生活质量的主观评价；本研究分别考察消极情绪、积极情绪和生活满意度。

**存储分数**：数据文件中提供的三个结局数值。计分转换依据尚未核实，误差以这些存储单位报告。

**主分析**：在首次查看留出结果之前固定的参与者处理、模型选择和评价方案。

**探索性优化**：查看过原留出结果之后执行的有限配置搜索；其结果保留探索性地位。

**聚合结果**：按样本、模型、结局或特征汇总的统计量，不包含可识别参与者的逐人记录。

**成稿**：在已核实研究事实之上形成的完整论证文本；编辑完成不等于作者审批或投稿授权。

**证据定位**：将研究论断指向本研究结果或文献中的具体页码、章节与段落，并说明适用范围。
